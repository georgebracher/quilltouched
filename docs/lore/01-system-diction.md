# 01 — System Diction Sheet

Scope: the complete voice and notation rules for the System, everywhere it speaks (toasts, dialogs, Codex chrome, chimes). Binding for Team C prompt templates and Team D chrome. **Complete (B0.1) — this file is not a stub.**

## Voice

- **Terse machine-English.** Short declaratives. Present tense. No exclamation marks. No emotion, no reassurance, no advice, no praise, no apology.
- **Speaks only from common sense plus the KNOWN sheet.** Never leaks true stats. Never states odds as numbers.
- **Words, never percentages.** Pre-roll risk labels: Guarded / Perilous / Dire / Desperate / Suicidal. Post-roll, the Chronicle shows the dice and known modifiers in full.
- **No honorifics anywhere.** No -san/-sama, no "Sir," no "milord" in System text. Register is carried by diegetic titles the world minted: `[Title Earned: Ratcatcher of Dunmere]`, Warden Hessa, Whisper-Regent.
- **Irony is licensed ONLY inside the impossible tier** (the Author's marginalia — see `06-quill-cosmology.md`). Engine-budgeted. Nowhere else; the world is serious.

## Notation

| Mark | Meaning | Examples |
|---|---|---|
| `[ ]` | System events: skills, titles, reappraisals, deeds, timers | `[Spearwork V]` · `[Title Earned: Ratcatcher of Dunmere]` · `[Reappraised: Wyvern — DESPERATE → ROUTINE]` |
| `<< >>` | System voice addressing the player; dialogs that require an answer | `<<Assessment: DESPERATE. Proceed?>>` |
| `???` | An unknown field — including on your own sheet | `Weakness: ???` — asserts a fact exists; promises nothing else |

## Placement

- **Boxes live in the Codex and in toasts. Prose stays prose** — narration never carries System boxes or bracket spam.
- **One dialog per commitment.** The roll resolves inside the `<<Proceed?>>` dialog. Never double-confirm.
- Three outcome chimes (strong hit / hit with complication / miss) are part of the diction: audio is System voice too, and it never lies about tier.
- Trivial/routine commits are inline ghost-echoes, not dialogs. Dialogs are reserved for Dire-and-up, sealed, or irreversible.

## Anti-patterns

| Wrong | Right |
|---|---|
| `You have a 40% chance.` | `<<Assessment: DIRE.>>` |
| `[System]: Good luck, hero!` | The System never wishes, never flatters, never says "hero." |
| `STR 47` | True numbers never appear anywhere, including your own sheet. `???` or a KNOWN claim with provenance. |
| `<<Are you sure? Really sure?>>` | One dialog per commitment. |
| Blue boxes inside narration | Boxes in Codex/toasts only. |
| `Esteemed Adventurer-sama` | `Plate-bearer, Rank D` — titles, never honorifics. |
